# C++ Banking System

A beginner-friendly C++ banking system project built using classes and objects.

## Current Features

- Login screen
-  Welcome screen
-  Account options menu
-  Add money / deposit
-  Withdraw money
-  Display account balance
- Exit option

## Technologies

-  C++
-  Object-Oriented Programming (OOP)
-  Classes and Objects

## Project Status

🚧 Currently under development.

More banking features and file-based data storage will be added as the project progresses.
